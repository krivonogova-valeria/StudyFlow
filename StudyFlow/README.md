# StudyFlow

Веб-приложение для организации учебного процесса студента: расписание пар, учебные задачи с дедлайнами и приоритетами, прогресс выполнения и карточки для повторения.

Учебный проект. Все данные хранятся локально в браузере (`localStorage`), сервера нет.

## Возможности

- Онбординг из трёх экранов и приветственный экран
- Регистрация и вход (локально, без сервера)
- Задачи: название, предмет, дедлайн, приоритет, выполнение и отмена, удаление
- Прогресс: процент выполнения, счётчик «N из M», анимированный Progress Bar
- Фильтры (все / активные / выполненные) и сортировка (по дедлайну, по приоритету, срочные сначала)
- Контроль дедлайнов: просроченные подсвечены, значок предупреждения, остаток времени
- Расписание, карточки для повторения, профиль
- Адаптивный интерфейс, навигация с клавиатуры, ARIA-атрибуты

## Технологии

HTML5, CSS3, JavaScript (ES-модули), `localStorage`, иконки Lucide. Без сборщиков и фреймворков.

## Запуск

Проект использует ES-модули, поэтому его нужно запускать через локальный сервер, а не двойным щелчком по `index.html`.

1. Откройте папку проекта в VS Code.
2. Установите расширение **Live Server**.
3. Нажмите правой кнопкой на `index.html` и выберите **Open with Live Server**.

## Использование

1. Пройдите онбординг и создайте аккаунт.
2. В разделе «Задачи» добавьте задачу: название и дедлайн обязательны.
3. Отметьте задачу выполненной нажатием на квадратик слева, смените приоритет нажатием на флажок, удалите корзиной.
4. Фильтруйте и сортируйте список, следите за прогрессом вверху экрана.

## Известные ограничения

- Данные хранятся только в этом браузере на этом устройстве, синхронизации между устройствами нет.
- Аккаунт локальный и демонстрационный, это не замена серверной авторизации. Не используйте реальные пароли.
- Вход через Google и восстановление пароля пока заглушки.
- Уведомлений о приближающихся дедлайнах нет.
