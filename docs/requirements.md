# Требования к проекту StudyFlow

## 1. Цель и задачи

**Цель:** помочь студенту не терять дедлайны и видеть реальный прогресс по учёбе.

**Задачи:**
1. Быстрое добавление учебных задач с дедлайном и приоритетом.
2. Показ процента выполнения и ближайших сроков.
3. Фильтрация и сортировка задач.
4. Сохранение данных между сеансами без сервера (`localStorage`).
5. Удобная работа на смартфоне и компьютере.

## 2. Целевая аудитория

Студенты колледжей и вузов (17–25 лет): несколько предметов одновременно, много мелких дедлайнов, расписание меняется по неделям.

## 3. Проблемы студентов и решения

| Проблема | Решение StudyFlow |
|---|---|
| Дедлайны в чатах и «в голове» | Единый список задач с подсветкой просрочки |
| Непонятно, что делать первым | Приоритеты и сортировка |
| Нет ощущения прогресса | Progress Bar, стрик, достижения |
| Расписание в разных местах | Раздел «Расписание» |
| Зубрёжка без системы | Флеш-карточки |
